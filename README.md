# PGPractice

Practice GnuPG against a friendly server: upload your public key, then encrypt, sign,
decrypt and verify messages using the real `gpg` CLI. Live at **https://pgpractice.appfarms.org**.

Runs on the Cloudflare free tier: one Worker (API + static assets), D1, and a daily cron.
See [PLAN.md](PLAN.md) for the design.

## Layout

```
src/shared/exercises.ts   exercise catalogue (lesson text + types), used by worker and web
src/worker/               Hono API, OpenPGP.js graders, sessions, D1 store, WKD
src/web/                  vanilla TS frontend (Vite), packet inspector
migrations/               D1 schema
scripts/gen-server-key.mjs  generates the server key into secrets/ (gitignored)
test/unit.test.ts         vitest unit tests
test/e2e.mjs              full run of every exercise using the real gpg binary
```

## Development

```sh
npm install
npm run gen-server-key              # once; writes secrets/server-*.asc
# .dev.vars needs SERVER_PRIVATE_KEY (armored, \n-escaped, quoted) and SESSION_SECRET (>= 32 chars)
npm run db:migrate:local
npm run dev                         # http://localhost:8787
npm test                            # unit tests
node test/e2e.mjs                   # e2e against BASE (default http://127.0.0.1:8787)
KEYTYPE=rsa3072 node test/e2e.mjs   # same with an RSA key
npm run typecheck
```

## Deployment

```sh
npm run db:migrate:remote           # when migrations change
npm run deploy                      # vite build + wrangler deploy
```

Secrets are stored on the Worker (`SERVER_PRIVATE_KEY`, `SESSION_SECRET`). To rotate:

```sh
npx wrangler secret put SESSION_SECRET          # signs everyone out
npx wrangler secret put SERVER_PRIVATE_KEY < secrets/server-private.asc
```

**Back up `secrets/` offline** — it holds the server private key and its revocation
certificate (`server-revocation.asc`). If the key is ever compromised, publish the revocation
certificate and generate a new key.

## Notes

- The server key is Ed25519/Cv25519 generated by OpenPGP.js so it does not advertise
  LibrePGP OCB; GnuPG therefore encrypts to it with SEIPDv1, which OpenPGP.js reads.
  The server only performs cheap private-key operations, keeping requests well under the
  10 ms free-tier CPU limit (measured ≤ 6 ms in production).
- WKD (direct method) is served at `/.well-known/openpgpkey/hu/…`, so
  `gpg --locate-keys practice@pgpractice.appfarms.org` works.
- Data is purged by the daily cron 30 days after a key's last activity (`RETENTION_DAYS`).
